Bookmark Everything

Vimium-style hints for URLs, files, folders, and apps. Type two letters, it opens.

Open

Super+BOpen or close the launcher. (Another key if that one was taken; hover the bar icon to see which.)
Bar iconClick: open. Right-click: options.
bkmkeSame, from a terminal. bkmke help lists subcommands.

Hints

Each bookmark shows a two-letter code on the left. Type it and the bookmark opens. Typing the first letter narrows the list.

Codes are assigned automatically (aa, ab, …). To pick your own, edit the bookmark and type it in the Hint field: gh for GitHub, no for notes. zz always opens this page.

Search

Press / and type. Matches names, tags, notes, URLs, paths, and app names. Letters go to the search box; the shortcuts above still work.

↑ ↓ EnterChoose and open
Ctrl+Backspace / Ctrl+UDelete a word / clear
EscClear, then back to Hints

Mouse

  • Click a row to open it. Right-click, or the ⋯ on the highlighted row: Open / Edit / Delete.
  • + adds. HINTS / SEARCH switches mode. The gear opens Options. Click outside to close.

Add and edit

Fields: Type, Name, Target, Tags, Notes, Hint. Tab next field, Enter save, Esc cancel.

  • Target: paste a URL or type a path; the type is detected. File or folder is decided from what is on disk.
  • Paths complete like a shell: Tab in the empty field browses from home; Tab again extends or cycles; ↑ ↓ Enter pick. Ctrl+Space or Places lists folders and files you already use (file-manager sidebar, zoxide, recent files).
  • Application: the Target field becomes a picker; type to search installed apps.
  • Name is optional: defaults to the site, file, or app name.
  • Hint: pre-filled with the next free code. Type your own two letters instead. If another bookmark has that code, the two swap. The reset button beside the field, or Ctrl+R, restores the default.

Add apps in bulk

Ctrl+A in the launcher (or bkmke apps).

Space or clickSelect / deselect
Ctrl+ASelect everything listed (type a filter first to narrow it)
EnterAdd the selected apps. Ones already bookmarked are skipped.
EscClear selection, then filter, then leave

Types

URLhttps://… (bare domains get https://). Opens in the default browser.
FilePath, ~/ allowed. Opens in its default app.
FolderPath, ~/ allowed. Opens in the file manager.
ApplicationDesktop entry id, e.g. firefox. Launches like the app menu.

A missing file, folder, or app is shown struck through; opening it sends a notification. Restore it and the mark clears.

Options

Right-click the bar icon, or Ctrl+K / the gear in the launcher.

  • Hotkey: type a combination such as SUPER + ALT + B and press Enter. A key already in use is refused and named. To use it anyway, free it first in ~/.config/hypr/bindings.lua (hl.unbind("SUPER + B")).
  • Built-in hotkey off: the screen shows the line to add to bindings.lua if you want to bind it yourself.
  • Icon in the bar: hide or show it. The hotkey keeps working either way.
  • Open in Search mode: start in Search instead of Hints.
  • Updates: the plugin checks this repository twice a day. A new version gives one notification and an Update now button here. Update automatically installs new versions by itself. "updateCheck": false in the settings file stops the check.

Import and export

Ctrl+O writes all bookmarks to a JSON file. Ctrl+I merges one in: same id replaces, new ids are added, clashing hints are reassigned. Your file is backed up first.

Files

~/.config/omarchy/bookmark-everything.json           bookmarks (plain JSON, edit freely; reloads on save)
~/.config/omarchy/bookmark-everything.settings.json  options (hotkey, icon, open mode), created when you change one
{ "hint": "aa", "type": "url", "name": "Arch Wiki", "target": "https://wiki.archlinux.org", "tags": ["linux"], "notes": "" }

Command line

bkmke                    open or close
bkmke search             open in Search mode
bkmke add . | <url|path>  add (relative paths resolve)
bkmke clip               add from clipboard
bkmke apps               add apps in bulk
bkmke import | export    JSON in / out
bkmke hotkey [combo|off] show, set, or turn off the hotkey
bkmke icon on|off        show or hide the bar icon
bkmke mode hints|search  set the mode the launcher opens in
bkmke update             update the plugin (shows the diff first)
bkmke options            open Options

675 codes (aa–zy) are available; anything beyond that is still reachable by search.
