Bookmark Everything

A keyboard-first launcher for bookmarked URLs, files, folders, and applications. Local only. No accounts, no network.

Open the launcher

KeyWhat it does
Super + BToggle the launcher in the configured mode (Hints by default). If that key was already taken when the plugin loaded, another one was chosen; see Hotkey.
Bookmark icon in the barClick to open. Hover to see the current hotkey. Middle-click opens in Search mode. Right-click for options.
bkmkeThe same from a terminal. Try bkmke help for the other subcommands.

Hotkey

The plugin registers its key by itself when it loads, so nothing needs editing. It prefers Super + B. If something on your machine already uses that, it takes the first free key from a short list (Super + Alt + B first) and tells you once with a notification.

To…Do this
See the current keyHover the bookmark icon in the bar, or look at the chip in the launcher's header. Omarchy's own keybindings menu (Super + K) lists it as “Bookmark Everything”.
Change itRight-click the bar icon and choose Change hotkey…, or press Ctrl + K in the launcher. Type a combination such as SUPER + ALT + B, or pick one of the suggestions with ↑ ↓ or the mouse. Each suggestion says whether it is free or what already uses it. Enter applies.
Turn the built-in key offThe same options card, the Turn off button in the chooser, or bkmke hotkey off. You can then bind the launcher yourself in ~/.config/hypr/bindings.lua.
Use a key that is already takenFree it first. For an Omarchy default or one of your own, add hl.unbind("SUPER + B") (with the key in question) to ~/.config/hypr/bindings.lua; for another plugin, change that plugin's key. Then choose it here.

Why type instead of press: Hyprland acts on a bound combination before the launcher could see it, so “press the keys you want” would launch whatever holds them.

The key lives in the running compositor, not in a file under ~/.config/hypr. It is put back after hyprctl reload and removed when the plugin is disabled or removed. If you already bound the launcher yourself in bindings.lua, the plugin sees the key in use and leaves it to you.

Hint mode

Every bookmark has a stable two-letter code shown in the left column. Type the two letters and the bookmark opens immediately. Typing the first letter narrows the list to matching codes.

Search mode

Type to filter. Matching is fuzzy and runs over the name, tags, notes, URL or path, and the application name. All the shortcuts above still work here, except that letters go into the search box.

KeyAction
↑ ↓ then EnterChoose and launch
Ctrl+Backspace / Ctrl+UDelete the last word / clear the search
EscClear the search, then go back to Hints (or close, if the launcher opened in Search mode)

Mouse

  • Click a row to launch it. Right-click, or click the ⋯ on the highlighted row, for Open / Edit / Delete.
  • The + in the header adds a bookmark. The HINTS / SEARCH badge switches mode.
  • Click outside the card to close.

Adding and editing

The Add dialog has Type (URL, File or folder, Application), Name, Target, Tags, Notes, and Hint fields. Tab moves between fields, Enter saves, Esc cancels.

  • Pasting a URL into Target selects URL automatically; typing a path selects File or folder. Whether it is saved as a file or a folder is decided when you save, from what is actually on disk.
  • For File or folder, the Target field works like a shell: press Tab in the empty field to start browsing from your home folder, then Tab extends to the common prefix and cycles through matches; ↑ ↓ browse the list and Enter accepts (a folder keeps descending). Ctrl+Space, or the Places button, opens a picker of folders and files you already use: your Files sidebar bookmarks, zoxide's most-visited folders, and recent files. Nothing extra to install; sources you don't have are skipped.
  • For Application, the Target field becomes a picker: press Enter or start typing to search installed applications.
  • Name is optional. It defaults to the site host, the file name, or the application name.
  • Hint is auto-assigned to the next free code. If you type a code another bookmark already uses, the form says Swaps with … and, on save, the two bookmarks trade codes: the other one takes the code this entry had (or would have been given). The 󰑐 button next to the field, or Ctrl+R, restores the default code.
  • Saving checks that the target exists (paths), looks like a URL, or matches an installed application.

Adding many applications at once

Press Ctrl+A in the launcher (or run bkmke apps) to open the application picker in bulk mode. The same picker appears from the Add dialog when the type is Application.

KeyAction
Space or clickSelect or deselect the highlighted application
Ctrl+ASelect every application currently listed. Type a filter first to narrow the list, or leave it empty to select all installed applications.
EnterAdd every selected application as its own bookmark (name, icon, and notes come from the desktop entry, tagged app). Applications already bookmarked are skipped.
EscClear the selection, then the filter, then leave the picker

Missing targets

A bookmark whose application is not installed, or whose file or folder no longer exists, is shown struck through with a not installed / file missing / folder missing note. Launching it sends a notification instead of failing silently. The check runs every time the launcher opens, so reinstalling the app or restoring the file clears the flag. Imports also report any applications they could not match.

Where things live

~/.config/omarchy/bookmark-everything.json              your bookmarks (plain JSON, edit freely)
~/.config/omarchy/bookmark-everything.json.bak-<time>  automatic backup taken before each import
~/.config/omarchy/plugins/io.github.decadentsavant.bookmark-everything/      the plugin itself (this page included)
~/.config/omarchy/shell.json                  open mode, see below
~/.config/omarchy/bookmark-everything.settings.json  your hotkey choice; created the first time you change it

An entry looks like this. The file reloads automatically when you edit it by hand; missing hints or ids are filled in.

{
  "id": "pacman-cheatsheet",
  "hint": "aa",
  "type": "file",
  "name": "Pacman & Yay Cheatsheet",
  "target": "~/Documents/pacman-yay-cheatsheet.html",
  "tags": ["linux", "arch", "reference"],
  "notes": "Common package commands"
}

Settings

Open mode is set on the plugin's entry in ~/.config/omarchy/shell.json:

"plugins": [
  { "id": "io.github.decadentsavant.bookmark-everything", "openMode": "search" }
]

The hotkey is covered above. To open straight into Search from a second key of your own, pass a mode in the payload from ~/.config/hypr/bindings.lua:

o.bind("SUPER + SHIFT + B", "Bookmark search", "omarchy-shell shell summon io.github.decadentsavant.bookmark-everything '{\"mode\":\"search\"}'")

Import and export

Both use the same JSON format as the storage file. Import merges: an entry with the same id replaces the old one, new ids are appended, and any imported hint that collides with an existing one is reassigned so your codes stay stable. A backup is written before the merge.

bookmarks export                 # ~/bookmark-everything-export-<date>.json
bkmke export ~/my.json
bkmke import ~/my.json
bkmke add https://example.com
bkmke add .                  # bookmark the current folder
bkmke add docs/notes.md      # relative paths are resolved
bkmke clip                   # add from clipboard
bkmke apps                   # pick installed applications, multi-select
bkmke search                 # open in Search mode
There are 675 usable hint codes (aa–zy). Bookmarks beyond that are still reachable in Search mode.
