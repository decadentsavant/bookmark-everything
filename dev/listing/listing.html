BOOKMARK
EVERYTHING

Two letters, and anything opens.
Bookmark Everything is a keyboard-first launcher for Omarchy. Press Super+B, type two letters, and a URL, file, folder, or app opens. One JSON file, no accounts, no network.
★
What it does
aa

Two-letter hints

Every bookmark gets a code that never changes under you. Type it, it opens.

🔍

Fuzzy search

Press / and type. Names, tags, notes, URLs, paths, application names.

🗂️

URLs, files, folders, apps

Each opens the way Omarchy would. Paste a target; the type is detected.

⚡

Works the moment it is installed

Super+B and a bar icon, registered by the plugin. Nothing to add to bindings.lua.
